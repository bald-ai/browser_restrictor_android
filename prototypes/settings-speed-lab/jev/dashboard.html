Method and limits

This compares the frozen settings lab’s focused-edit agent with a Jev hybrid. The baseline predates the current phone app. Independent browser installations, alternating order, separate warmups, three repetitions for the five main edit scenarios. Existing UI polling stays unchanged. No voice or Android timing is included.
